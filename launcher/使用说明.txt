画布工作台 · Windows / macOS 桌面整合包

下载与完整指南：https://github.com/wenpengx/canvas-studio
发行包：https://github.com/wenpengx/canvas-studio/releases

一、选择版本
- Windows 10/11 x64：CanvasStudio-Windows-x64-版本.zip。
- Apple 芯片 Mac：CanvasStudio-macOS-arm64-版本.zip。
- Intel Mac：CanvasStudio-macOS-x64-版本.zip。
- 对应源码：CanvasStudio-Source-版本.zip。每份整合包也包含“对应源码.zip”。
普通使用者无需安装 Node、Go、FFmpeg 或 Docker；需安装 Chrome、Edge 或 Firefox 浏览器。

二、第一次使用
1. 完整解压 ZIP，不要在压缩软件内启动。
2. Windows 双击“画布工作台启动器.exe”。macOS 将“画布工作台启动器.app”移到“应用程序”后打开。
   macOS 包为临时签名，未使用 Apple Developer ID 或公证。若系统阻止打开，先确认来源与 SHA-256，再按系统“隐私与安全性”的“仍要打开”流程操作；不要关闭全局安全保护。
3. 在首页选择已安装的 Chrome、Edge 或 Firefox；也可指定浏览器程序（macOS 可选 .app）。
4. 打开“模型配置”，新增 OpenAI 兼容渠道，填写接口地址与 API Key。测试连接不会发起收费生成。
5. 为模型选择文字、图片或视频类型，再为白模导演、画布文字、图片和视频选择默认“渠道 · 模型”，保存全部配置。
6. 点击“一键启动工作台”。无模型配置时仍可手工编辑；在线生成需要服务商额度及对应能力。
7. 画布添加导演台节点后打开 CozyClay。底栏可保存场景、截图到画布、动画到画布；Ctrl+B（Mac 为 Cmd+B）打开 AI 面板。白模 AI 需支持工具调用，参考图需支持视觉输入。

三、数据和密钥
Windows 默认保存到整合包旁的 data 文件夹，portable.json 记录所选目录。
macOS 默认保存到 ~/Library/Application Support/Canvas Studio/data；定位文件在其上一级 Canvas Studio 目录。
数据库、素材、导演台项目、生成记录、日志、临时文件和独立浏览器资料都在数据目录内；下载默认在 data/outputs。
API Key 使用系统密钥存储加密（Windows DPAPI / macOS Keychain），没有明文回退。换电脑或系统用户后可能需要重新填写密钥。
不要向他人公开 data、portable.json 或包含私有素材的导出文件。
“切换数据目录”只切换工作区，不自动复制原数据。请先保存并停止服务；备份时复制整个数据目录并保留定位文件。

四、模型与工作流
- 渠道独立保存接口和密钥。同名模型可以在多个渠道使用，任务保持提交时的原渠道。
- 修改配置后刷新工作台；已打开的导演台请关闭重开。尚未结束的视频任务应保留原渠道和模型。
- Skill 管理支持新建、编辑、导入 Markdown/文本、导出和删除。规则作为模型指令，不执行本机脚本。
- FOR 文件夹循环通过原生目录选择器授权，支持图片、视频、音频、UTF-8 文本。每文件保留独立结果，暂停等待当前任务结束；重新打开后手动继续，不自动重新提交收费任务。
- 专属 MCP：画布助手的“MCP 连接”提供 canvas-studio-canvas 和 canvas-studio-director。使用支持 MCP 的客户端并保持启动器及对应工作区打开；先列出工作区再操作。
- 视频附件在本机 FFmpeg 解码抽帧，仅在用户发送时把抽帧图片交给视觉模型。损坏或超限文件会拒绝。

五、更新、停止和故障
更新源仅为 wenpengx/canvas-studio 的正式 Releases，不自动更新上游项目。
Windows：“检查与修复”读取版本列表，选择后下载校验并重启安装，也支持导入完整发行 ZIP。保留 data 和 portable.json；回退程序不回退数据格式。
macOS：“检查与修复”按当前芯片选择发行包，下载后核对大小与 SHA-256 并显示文件。退出启动器后，解压并手动替换 .app；数据在应用外保留。此版本不自动替换正在运行的 Mac 应用，也不使用 Windows 安装器。
关闭浏览器不停止后台服务。退出启动器会停止其启动的本机服务。卡住时可使用“强制停止进程”；它仅结束本启动器管理的进程，已提交的远端生成任务可能继续。
故障先查看“运行日志”和 data/logs；检查目录权限、磁盘空间、浏览器与模型接口。选择的数据目录不可用时，恢复该位置后重启。
