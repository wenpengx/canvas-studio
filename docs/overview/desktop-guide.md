# 桌面版使用指南

Canvas Studio 把无限画布、CozyClay 导演台和本机模型网关放进一个桌面启动器。普通使用者下载对应系统的完整整合包即可；源码 ZIP 用于阅读、修改和构建，不能当成已编译应用直接运行。

## 1. 选择下载文件

进入 [本仓库 Releases](https://github.com/wenpengx/canvas-studio/releases)，先看该版本说明和附件是否齐全，再选择自己的系统与处理器。Windows 与 macOS 发行包分别构建，某个平台构建成功不代表其他平台也已通过实机验收。

| 使用环境 | 应选文件 | 用途 |
| --- | --- | --- |
| Windows 10/11，Intel 或 AMD 64 位电脑 | `CanvasStudio-Windows-x64-<版本>.zip` | Windows 启动器和所需运行环境 |
| Apple Silicon Mac，M 系列芯片 | `CanvasStudio-macOS-arm64-<版本>.zip` | 原生 ARM64 应用和运行环境 |
| Intel Mac | `CanvasStudio-macOS-x64-<版本>.zip` | Intel 64 位应用和运行环境 |
| 查看代码或自行构建 | `CanvasStudio-Source-<版本>.zip`，或 GitHub 的 Source code | 源码、锁文件及构建说明，不含完整运行环境 |
| 校验下载是否完整 | 与整合包同名的 `.sha256` 文件 | SHA-256 摘要 |

macOS 可在苹果菜单 →“关于本机”查看芯片或处理器。当前不提供 Linux 桌面整合包，也不把 Windows ARM64 或其他架构当作已支持平台。

普通用户仍需自行安装一个支持的浏览器，并准备可用的 AI 服务接口及额度。整合包不包含外部 AI 模型权重，下载应用不会自动获得模型额度。

### 校验文件

Windows 在 PowerShell 中运行 `Get-FileHash -Algorithm SHA256 -LiteralPath '下载的完整ZIP路径'`；macOS 在终端运行 `shasum -a 256 '下载的完整ZIP路径'`。将结果与同名 `.sha256` 文件第一列比较，必须完全一致。下载不完整时重新下载，不要用缺文件的目录启动。

## 2. 解压并打开启动器

### Windows

1. 完整解压 ZIP 到可写目录，例如 `D:\CanvasStudio`。建议使用有足够空间的数据盘。
2. 保留整个目录结构，双击 `画布工作台启动器.exe`。不要只复制 EXE，也不要直接在压缩软件内运行。
3. 在首页选择已安装的 Edge、Chrome、Firefox，或指定浏览器程序。
4. 如果系统显示来源提示，先确认文件来自你选择的 Release，校验摘要后再决定是否运行。

### macOS

1. 解压与本机芯片相符的 ZIP。
2. 把 `画布工作台启动器.app` 放入 `/Applications` 或 `~/Applications`，再双击打开。使用说明和对应源码可另行保留。
3. 当前构建未使用 Developer ID 签名和 Apple 公证，macOS 可能阻止首次启动。确认来源与摘要后，按系统提示前往“系统设置 → 隐私与安全性”，对这个应用选择“仍要打开”。不同系统版本的提示有差异，参见 [Apple 官方打开说明](https://support.apple.com/zh-cn/102445)。
4. 不要关闭系统整体安全保护，也不要把运行中的应用留在压缩文件或只读位置。

当前 macOS 包的签名、公证、首次打开、钥匙串和实际更新行为以该版本说明及实机结果为准；CI 产生 ZIP 不等于这些项目已全部验收。

## 3. 配置渠道和模型

打开启动器的“模型配置”：

1. 新增一个渠道，填写能辨认用途的名称、服务商提供的接口地址和 API Key。
2. 测试连接并读取模型；如果服务商不支持模型列表，按其说明手动填写模型名称。
3. 为模型指定文字、图片或视频类别。名称相同的模型可以属于不同渠道，调用时由所选渠道区分。
4. 分别设置白模导演、文字、图片、视频的默认“渠道 · 模型”。
5. 点击“保存全部配置”，然后启动工作台。修改后刷新画布；已打开的导演台需要关闭再打开。

白模导演使用支持工具调用的文字模型；发送参考图或视频抽帧图时，还需要模型支持视觉输入。普通文字接口可连接，不代表它具备图像生成、视频任务或工具调用能力。参数、接口格式与模型名须与服务商实际能力相符。

Windows 密钥使用系统加密，macOS 使用系统钥匙串；加密不可用时应按错误处理，不依赖明文回退。留空密钥会保留渠道原来的密钥；要移除密钥需使用对应的清除操作。停用或删除渠道、移除模型后，关联默认选择会清空，应重新选择。尚未结束的视频任务按原渠道查询，查询完成前应保留该渠道及模型。

连接测试不提交生成任务；真正开始生成会调用你配置的服务，并可能消耗该服务的额度。

## 4. 开始创作

点击“一键启动工作台”，等待服务进入运行状态，启动器会用所选浏览器打开专用工作区。

| 要做的事 | 操作入口和结果 |
| --- | --- |
| 组织创作材料 | 创建画布项目，添加文字、图片、视频等节点，用连线组织提示词、参考素材和后续结果 |
| 调用模型 | 在节点或生成配置中选择模型、填写提示词及参数，检查引用素材后再生成 |
| 复用素材 | 上传文件、拖入画布，或使用素材库与历史记录中的已有结果 |
| 使用导演台 | 添加导演台节点并打开 CozyClay，布置对象、镜头和动作；底部入口可保存场景、截图到画布、动画到画布 |
| 打开导演台 AI | 在导演台按 `Ctrl+B`（Mac 为 `Cmd+B`）打开 AI 面板，再选择对应渠道和模型 |
| 保存和导出 | 等待保存完成后离开；按画布或导演台入口导出项目、图片或视频 |

浏览器专用资料与普通浏览器资料隔离。更换首页的浏览器选项不会主动复制普通浏览器数据。关闭浏览器窗口不会停止后台服务；结束工作时先等待保存，再从启动器停止服务或退出。

复杂动作仍需人工调整。模型生成内容与失败原因由实际服务返回，界面功能或固定样本不代表所有模型都能产生相同效果。

## 5. 文件夹循环、Skill 和 MCP

### 文件夹循环

在画布底部工具栏添加“FOR 文件夹循环”，选择输入目录，连接后续节点并配置每一步。支持图片、视频、音频和 UTF-8 文本，按自然文件名顺序逐个执行；最多 2000 个文件，跳过符号链接。

每个文件保留独立输入和结果。暂停会等待当前任务结束；重新打开后手动继续。遇到“提交状态未确认”时先核对任务记录，再决定是否重试，避免重复提交。当前循环不支持嵌套循环，也不自动操作导演台或组。

### Skill

启动器“Skill 管理”可新建、编辑、导入 Markdown／文本、导出和删除规则。在文字节点或文字生成配置中选择模型和 Skill 后生成，最多同时选择五个。规则作为模型指令，不执行本机脚本。

### MCP

展开画布助手，进入“MCP 连接”，复制 `canvas-studio-canvas` 或 `canvas-studio-director` 配置。导演台底部也有独立 MCP 入口。支持 MCP stdio 的客户端可使用整合包自带 Node，无需安装原项目插件。

保持启动器和目标画布／导演台页面打开。客户端先列出工作区，再明确目标工作区；多个页面不能依靠猜测选择。移动整合包后重新复制配置；HTTP 端口变化后也需更新连接信息，stdio 桥会读取本机最新端口。连接配置包含本机凭据，应只交给你授权的客户端。

视频附件在本机解码为九宫格画面，仅在发送消息时把抽帧图交给视觉模型，并非直接上传整段原视频。超过 1 GB 或 10 小时的视频先裁短；损坏文件应按提示修复或换用可解码文件。

## 6. 保存、备份和迁移

桌面整合版把工作数据集中放在数据目录，具体路径以“存储设置”显示为准。Windows 默认使用解压目录内的 `data/`；macOS 默认使用 `~/Library/Application Support/Canvas Studio/data/`，应用本体与数据分开保存。

| 目录或文件 | 内容 |
| --- | --- |
| `workspace.db` | 本机项目、任务及相关数据库记录 |
| `settings.json` | 启动器设置、渠道与加密后的密钥 |
| `assets/`、`projects/` | 素材和导演台等项目文件 |
| `outputs/` | 导出、下载的结果 |
| `browser/` | 专用浏览器资料 |
| `logs/` | 启动、运行、AI 调用及更新日志 |
| `config/` | 本机连接、目录授权等配置 |

备份前等待保存完成，关闭工作台浏览器并停止服务，再复制完整数据目录和数据位置文件 `portable.json`。Windows 的位置文件在解压目录；macOS 在 `~/Library/Application Support/Canvas Studio/`。只备份导出的图片不会包含画布结构，只复制数据库也可能漏掉素材。应用不会自动为你保留额外的数据备份。

“切换数据目录”是切换工作区，不会把旧目录内容自动搬过去。若要继续已有项目，应选回原数据目录。迁移到另一台电脑、另一个系统用户或不同系统后，加密密钥可能无法解密，需要重新填写；项目格式的跨版本、跨平台兼容性须先用副本检查。

桌面整合版通过本机服务保存项目；源码 Web 版的存储方式不同：未登录时，画布与“我的素材”保存在浏览器本地；登录且账号同步可用时，可保存到账号／云端。本地直连模式的 API Key 保存在浏览器本地并由前端直连，不能与桌面网关的系统加密配置混为一谈。

## 7. 更新、回退和故障处理

Windows 在“检查与修复”中读取正式发行版本，选择目标版本后下载、校验并重启安装，也可导入完整 Windows 发行 ZIP。不能用 GitHub Source code ZIP 代替修复包。

macOS 当前采用手动更新：下载对应架构的新包，保存工作并退出启动器，再替换 `/Applications` 或 `~/Applications` 中的 `.app`。数据保存在应用外，不要删除数据目录。当前未实现 macOS 原位自动安装更新，不应把 Windows 的重启安装步骤套用到 Mac。

更新保留数据目录与位置配置。程序回退不会把新版数据转换成旧格式；回退前备份，旧版未必能打开新版项目。GitHub 连接失败不影响已有工作区继续运行，网络问题可检查系统代理或先用浏览器下载完整包。

| 现象 | 优先检查 |
| --- | --- |
| 找不到浏览器 | 首页重新选择已安装浏览器；macOS 支持 `/Applications` 与 `~/Applications` 下的 Chrome、Edge、Firefox，也可选择对应浏览器 `.app` |
| 服务无法启动 | 查看“运行日志”，核对数据盘是否在线、目录是否可写、文件是否完整 |
| 模型列表为空 | 核对接口、密钥、渠道启用状态；服务商不支持列表时手动填写模型名 |
| 能连接但不能生成 | 检查模型类别、工具／视觉能力、服务商协议、额度和返回错误 |
| 视频任务一直未确认 | 保留原渠道，先查任务记录；不要直接新建同一任务 |
| 数据盘不可用 | 恢复原盘或选回正确数据目录；应用不会自动把工作区迁移到系统盘 |
| 更新下载失败 | 检查系统代理及 GitHub 访问，或下载完整发行 ZIP 后按界面导入 |
| 服务卡住 | 先保存，再用首页或“检查与修复”的“强制停止进程”，然后重新启动 |

强制停止针对本启动器管理的后台进程；已经提交到远程模型服务的任务可能继续执行。向他人报告问题时提供版本、系统架构、操作步骤和相关错误，发送日志前移除密钥、私人素材与本机连接凭据。
